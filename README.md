# Apparate
A simple application, designed to pull audio data from youtube and download it in .webm format. It's designed after a tabletop campaign I'm running, so that's where the theming comes from.

Written in Node.js with React and Electron.

## Installing from Source
1. Clone repo
2. Install NPM packages (npm install)
3. Start application (npm start)

## Project Tasks
- Task 1: Set up Development Environment
    - Install necessary tools, dependencies, and software (node.js, react.js, electron.js)
    - Configure GitHub
- Task 2: Design the Application
    - Design UI/UX
- Task 3: Backend Development
    - Develop Backend Logic with node.js, electron
    - Set up React components
    - Set up Electron inter-process communication
- Task 4: Frontend Development
    - Tie logic into React component HTML
    - Develop UI/UX with HTML/CSS
- Task 5: Set up Security
    - Implement CORS
    - Set up input sanitization
    - Implement in-program check for valid URLs
- Task 6: Application Testing
    - Perform Unit/Integration testing on all features
    - Debug and fix issues identified
- Task 7: Documentation
    - Create a comprehensive README
